# EHW-5.2 board leg: FAIL — evidence package (Claude → ChatGPT, 2026-07-03)

## Verdict
impl_12 (rm_memetic_struct combined VRC + lite train unit) loaded clean on the
board, but the smoke firmware reports the FAIL word. The VRC island is fully
healthy on silicon; the divergence is confined to the HW-train-unit arm
(adapt_tu): after 1 epoch its genome differs from the CPU golden in 2 bytes and
its SSE is +51. Deterministic — two independent loadb runs produced identical
words.

  WHS +0.023, both write_bitstream Complete, 0 ERROR).
- Firmware was re-baked first with a board-only evidence carousel in the
  `#ifndef MEMETIC_STRUCT_TRAIN_HOST_STUB` final loop (EHW-3.2 precedent: every

  board branch only; all 17 host gates re-run green; verify-image OK (4344 B).

## What I already checked (all clean — don't re-litigate)
1. Wrapper handshake in tpu_rp_rm_memetic_struct.v is the same start/pending
   pattern as the silicon-proven tpu_rp_rm_memetic_train.v (EHW-4.3/4.4
   bit-exact). Double-write on held-stb is idempotent for all SR/TU data regs;
   UPD commands are guarded by !upd_active.
2. Address maps verified end-to-end (SR_MASK→0x410→word4, MARKER→0x420,
   GEN→0x440+4i; TU off[8:2] covers 0x800..0x934 incl. BUSY word 77).
3. LOSS_D2 / D1 execute in ONE clocked cycle in memetic_train_unit_lite.v, so
   the firmware's immediate D2/D1 readback (no tu_wait_idle) is safe; the
   serialized phases (UPD_L2 8 cy, UPD_L1 16 cy) complete long before the first
   XBUS BUSY read can even return.
4. Arithmetic equivalence stub-vs-RTL checked term by term: leaky_apply
   ((x+2)>>>2 == qmul(x,64)), clampd ±16384 == MEM_DELTA_CLAMP, clamperr ±2^20
   == MEM_ERR_CLAMP, update sat16(w-(g>>>7)), qmul_sq 44-bit == int64 qmul —
   all identical semantics.
5. Timing met, DRC clean, deterministic behavior → not a marginal-Si smell.

## Gate coverage gaps (the bug lives in one of these blind spots)
A. The RTL tb in tests/compare_memetic_struct_train.py drives the TU with a
   SMOKE sequence only (1 weight write, 1 dw, 1 UPD_L2, busy poll, 1 readback).
   The full 40-sample epoch (LOSS_D2 → D1 → UPD_L2 → UPD_L1 → master_read per
   sample) has never been RTL-simulated against the C golden.
B. The host stub's sr_read(SR_OUTPUT) returns a constant 0 and sr_phi_hw is
   modeled — the per-sample fabric phi path (sr_write(SR_INPUT,row) →
   sr_read(SR_OUTPUT)) is exercised ONLY on the board, and it is exactly the
   new-in-5.2 ingredient that EHW-4.4 (bit-exact) did not have. The sim tb
   checks only rows 7 and 0 after genome load.
